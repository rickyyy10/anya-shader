What is computed

不是一张贴上去的图片。

Channel 只负责保存结构化输入。相机转动后，所有可见像素都会重新追踪光线； 最终画面、遮挡关系、法线与光照均由 GLSL 即时计算。

01 / GEOMETRY

真实三角网格

读取原始模型拓扑，不用简化的 SDF 几何代替角色轮廓。

02 / ACCELERATION

逐像素 BVH 遍历

每条相机光线遍历加速树，只测试可能命中的三角形节点。

03 / SHADING

实时材质与光照

命中后插值法线和 UV，再计算纹理、明暗、轮廓和地面效果。

  1. GLB mesh模型源文件
  2. RGBA8 packing量化并编码数据
  3. BVH traversal定位候选节点
  4. Triangle hit计算重心坐标
  5. Final pixel材质与光照

Four inputs

Channel 是数据缓冲，不是最终答案。

Shadertoy 的 Image Shader 没有传统 Vertex Buffer 和 Index Buffer 接口， 因此将网格数据打包成可由片元着色器随机访问的 PNG 数据纹理。

iChannel0

BVH Nodes

包围盒、子节点索引和叶节点三角形范围。

Nearest · Clamp · VFlip Off
iChannel1

Vertex Data

16 位量化位置、八面体法线编码和 UV 坐标。

Nearest · Clamp · VFlip Off
iChannel2

Triangle Indices

保存网格拓扑的 24 位三角形顶点索引。

Nearest · Clamp · VFlip Off
iChannel3

Albedo Atlas

模型原始底色图集，由命中点的插值 UV 采样。

Mipmap · Repeat · VFlip Off
